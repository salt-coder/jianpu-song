# 给 QQ Agent 装「简谱点歌」技能 · 安装说明

装完之后，群友在群里发一串简谱数字（例如 `1166556`），机器人就会把它变成音乐，**以语音条发到群里**。

---

## 一、需要什么

| 项目 | 要求 |
|---|---|
| QQ Agent | 已经装好并能正常运行（版本 0.4 系列） |
| **Python** | **3.8 或更高**（唯一需要你装的东西） |
| ffmpeg / Node.js / 音源 | **不用装**，已经打包在 `jianpu-tools` 里 |

> 装 Python 时**务必勾选** `Add python.exe to PATH`，否则机器人找不到它。
> 下载：<https://www.python.org/downloads/>

---

## 二、安装（两种方式，选一种）

### 方式 A：一键安装（推荐）

1. 把本压缩包**解压**到任意位置（例如桌面）
2. **右键** `一键安装.cmd` → **以管理员身份运行**（或直接双击）
3. 看到 `Done!` 就好了

脚本会自动找到 QQ Agent 的安装目录，把两样东西复制进去：
- `skills\jianpu-song\` ← 技能本体
- `jianpu-tools\` ← 工具链（约 205 MB，复制需要十几秒）

### 方式 B：手动复制（一键脚本没找到目录时）

1. 右键 QQ Agent 的桌面快捷方式 → **打开文件所在位置**，进入
   `…\QQ Agent\resources\app\`（这个目录里有 `plugins`、`src`、`ui` 等文件夹）
2. 把本包里的 **`skills\jianpu-song`** 整个文件夹复制到 `resources\app\skills\` 下
   （没有 `skills` 文件夹就自己新建一个）
3. 把本包里的 **`jianpu-tools`** 整个文件夹复制到 `resources\app\` 下
4. 最终结构应该是：
   ```
   QQ Agent\resources\app\
   ├── skills\
   │   └── jianpu-song\      ← skill.json + index.js
   ├── jianpu-tools\         ← 3.py + ffmpeg\ + node\ + soundfonts\ + engine\
   ├── plugins\
   ├── src\
   └── ui\
   ```

---

## 三、确认装好了

1. 打开（或重启）QQ Agent 控制台
2. 点顶部的 **「技能」页签**（注意：是「技能」，不是「插件」）
3. 应该能看到一项：

| 显示 | 值 |
|---|---|
| 名称 | **简谱点歌** |
| 状态 | 已启用 · 可用 |
| 工具 | 简谱点歌（发语音条）`play_jianpu` |

> 热重载默认开着，**不用重启**就会自动加载。

---

## 四、试一下

在群里发：

```
1166556
```

机器人应该会回一个语音条（口琴音色的小片段）。

也可以说得更明确一点：

```
用钢琴弹一下 1 2 3 1|3 4 5-
来段小提琴：1' 7 6 5
换成口琴吹 1166556
```

**支持的音色**：口琴 / 钢琴 / 电钢 / 八音盒 / 吉他 / 小提琴 / 大提琴 / 弦乐 / 长笛 / 排箫 / 萨克斯 / 正弦波

**简谱记号**：`1`~`7` 音级、`0` 休止、`#4` 升号、`1'` 高八度、`1,` 或 `（1）` 低八度、`1-` 延长、`1/` 减时、`1.` 附点、空格分句、`||` 换气

---

## 五、可以在技能设置里改（QQ Agent →「技能」→ 简谱点歌）

| 设置项 | 默认 | 说明 |
|---|---|---|
| 3.py 的完整路径 | 留空（自动查找） | 一般不用填 |
| Python 解释器路径 | 留空（自动查找） | 找不到 Python 时手填，如 `C:\Python311\python.exe` |
| 默认音色 | 口琴 | 群友没指定时用哪个 |
| 默认速度 / 调号 | 120 / C | 可改成 92、`1=D` 等 |
| 以语音条发送 | 开 | 关掉则改为发送 MP3 文件 |
| 最长音符数 / 时长 / 超时 | 160 / 120s / 180s | 防止刷屏 |

## 六、遇到问题

| 现象 | 原因与处理 |
|---|---|
| 技能页显示「找不到生成脚本 3.py」 | `jianpu-tools` 没放对位置。确认它在 `resources\app\jianpu-tools\`；或在技能设置里手填 3.py 路径 |
| 技能页显示「找不到 Python」/ 报 `spawn python ENOENT` | 装 Python 时没勾 `Add python.exe to PATH`。重装并勾上，或在技能设置里填「Python 解释器路径」 |
| 群里发数字没反应 | ① 确认「技能」页里它是**已启用**；② 数字要像简谱（只含 0~7 和记号）；③ 直接说「用口琴吹 1166556」引导它 |
| 收到的是文件而不是语音条 | 协议端不支持语音时会自动降级为群文件，属正常 |
| 想省磁盘空间 | `jianpu-tools\node\`（89 MB，删了就没有 287 种乐器音色）、`ffmpeg\`（84 MB，删了只能出 WAV）、`soundfonts\`（31 MB）都可以删，程序会自动降级 |

## 七、包里都是什么

```
skills\jianpu-song\     技能本体（skill.json + index.js）
jianpu-tools\           工具链
├── 3.py                简谱 → 音频主程序
├── sf2_render.cjs      SF2 离线渲染器
├── engine\             FluidSynth wasm 引擎
├── soundfonts\         GeneralUser GS（287 种乐器音色）
├── ffmpeg\bin\         ffmpeg（MP3 + 响度标准化）
├── node\               Node.js（渲染 SF2 用）
└── harmonica\          口琴采样（可选）
一键安装.cmd            自动安装脚本
安装说明.md             本文件
```

工具链里还附了 `使用说明.md`（完整命令行用法）和 `授权说明.md`（第三方组件授权）。
