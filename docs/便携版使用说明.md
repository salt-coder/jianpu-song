# 简谱转音乐 · 便携版使用说明

把**简谱数字**变成**音频文件**（钢琴 / 小提琴 / 长笛 / 口琴…共 287 种音色），一个文件夹拷到哪台电脑都能用。

---

## 一、唯一的前提

**只要装了 Python 3.8 或更高版本**就行（其它全部随包附带）。

> 没装的话去 <https://www.python.org/downloads/> 下载，安装时**务必勾选** `Add python.exe to PATH`。

ffmpeg、Node.js、音源、引擎都在包里，**不需要另外装任何东西**。

---

## 二、三种用法（挑一种）

### 用法 1：双击 `run.cmd`（最简单）

会跑内置示例《两只老虎》，生成 `two_tigers.mp3` 到当前目录。

### 用法 2：在文件夹里开命令行（推荐）

```bat
cd /d 本文件夹路径

python -X utf8 3.py "1 2 3 1|3 4 5-" --engine sf2 --gm 钢琴 -o 我的曲子.mp3
```

> `-X utf8` 是必须的：Windows 默认用 GBK 读文件，中文会乱码。
> 也可以先执行 `chcp 65001` 再运行。

### 用法 3：直接把简谱当参数

```bat
run.cmd "1 2 3 1|3 4 5-|5 6 5 4 3 1|1 5, 1-||" --engine sf2 --gm 小提琴 -o out.mp3
```

## 三、看有哪些音色 / 示例 / 参数

```bat
python -X utf8 3.py --gm list        :: 23 个中文音色名
python -X utf8 3.py --demo list      :: 内置示例
python -X utf8 3.py --help           :: 全部参数
```

**常用音色名**：钢琴 / 电钢 / 八音盒 / 管风琴 / 口琴 / 吉他 / 小提琴 / 大提琴 / 竖琴 / 弦乐 / 合唱 / 小号 / 萨克斯 / 长笛 / 排箫 / 正弦波

**也能用音色号**（GM 标准 0~127）：`--program 0` 钢琴、`24` 吉他、`40` 小提琴、`48` 弦乐、`73` 长笛

## 四、简谱记号速查

| 记号 | 含义 | 例子 |
|---|---|---|
| `1`~`7` | 音级（1 = 主音） | `1 2 3` = do re mi |
| `0` | 休止符 | `1 0/ 2` |
| `#4` `b7` | 升 / 降号 | `#4` = 升 fa |
| `1'` `1^` `1+` | 高八度（可叠加 `1''`） | `1'` 比 `1` 高八度 |
| `1,` / `_1` / `（1）` | 低八度（三种写法都行） | `1,` 比 `1` 低八度 |
| `1-` | 延长线：+1 拍（`5--` = 3 拍） | `5-` |
| `1/` | 减时线：减半（`1//` = ¼ 拍） | `1/ 2/ 3/` |
| `1.` | 附点：×1.5（`1..` = ×1.75） | `1. 2` |
| `1:0.75` | 直接指定拍数 | `1:0.3` |
| `1~1` 或 `1 1~` | 连音线（两种写法） | 合成一个 2 拍 |
| 空格 / `\|` / `\|\|` / 换行 | 分句停顿 0.25 拍 / 小节线 / 换气 1 拍 / 换行 1 拍 | — |

**时值可叠加**：`1/-` = 1.5 拍，`1./` = 0.75 拍，`1.` = 1.5 拍

## 五、三种音源引擎

| 引擎 | 参数 | 音色 | 需要什么 |
|---|---|---|---|
| **正弦波** | `--engine sine`（默认） | 电子音 | 无（最快） |
| **GM 音源** ⭐ | `--engine sf2` | **287 种真乐器** | 包内已带 Node + 音源 |
| 口琴采样 | `--engine sampler` | 口琴 | 包内已带采样 |

```bat
:: 钢琴
python -X utf8 3.py "1 2 3 1|3 4 5-" --engine sf2 --gm 钢琴 -o p.mp3

:: 换调 1=D、速度 92、加混响
python -X utf8 3.py "1 2 3 5|3 2 1-" --key 1=D --bpm 92 --engine sf2 --gm 小提琴 --reverb 110 -o v.mp3

:: 干声（不加音效和响度标准化）
python -X utf8 3.py "1 2 3" --engine sf2 --gm 长笛 --fx none --lufs off -o raw.mp3
```

**后处理** `--fx`：`light`（默认，轻微润色）/ `harmonica`（更重）/ `wide`（立体声加宽）/ `none`
**响度标准化** `--lufs`：默认 `-16`（流媒体标准），写 `off` 关闭

## 六、文件夹里都是什么

```
jianpu-portable/
├── 3.py                  ← 主程序（简谱 → 音频）
├── run.cmd               ← 双击就能跑
├── sf2_render.cjs        ← SF2 离线渲染器（Node 脚本）
├── engine/               ← FluidSynth wasm 引擎（sf2 引擎必需）
├── soundfonts/           ← GeneralUser GS 音源（287 种乐器，sf2 引擎必需）
├── ffmpeg/bin/           ← ffmpeg（导出 MP3 + 响度标准化）
├── node/                 ← Node.js（sf2 引擎必需）
├── harmonica/            ← 口琴 SFZ + 采样（sampler 引擎用，可选）
└── 使用说明.md            ← 本文件
```

**想瘦身的话**：

| 删掉 | 后果 |
|---|---|
| `node/`（89 MB） | 只剩正弦波和口琴采样；`--engine sf2` 会自动退化成正弦波并提示 |
| `ffmpeg/`（84 MB） | 不能导出 MP3，会自动改存 WAV（音质一样，只是文件大） |
| `soundfonts/`（31 MB） | 同上，`sf2` 不可用 |
| `harmonica/`（1 MB） | `--engine sampler` 不可用 |

> 如果目标电脑**已经装了** Node.js 或 ffmpeg（在 PATH 里），脚本会优先用系统里的，这几个文件夹就可以删。

## 七、常见问题

**Q：报错 `No module named 'pydub'`？**
A：不影响。pydub 只是可选依赖，没有它照样能生成。

**Q：报错 `没找到 ffmpeg` / 只生成了 WAV？**
A：确认 `ffmpeg\bin\ffmpeg.exe` 还在。生成 WAV 也没关系，音质完全一样，只是体积大。

**Q：`--engine sf2` 提示找不到 Node？**
A：确认 `node\node.exe` 还在；或者删掉 `--engine sf2` 用默认的正弦波。

**Q：中文乱码？**
A：运行时加 `-X utf8`：`python -X utf8 3.py ...`

**Q：想用口琴音色但 sampler 引擎声音怪？**
A：`sampler` 引擎有两个已知缺陷（长音循环点有咔声、释放音偏响），推荐改用
`--engine sf2 --gm 口琴`（GM 音源里的口琴音色）。
