# 简谱转音频工具 · 使用说明

> 一份文档覆盖：`3.py` 简谱转音频、三种音源引擎、287 种乐器音色、口琴/钢琴 SFZ 路线、网页模拟器、常见问题。
> 最后更新：2026-10-06 ｜ 主工具：`D:\deepseek\kouqin\3.py`

---

## 0. 一句话介绍

把**简谱数字**变成**音频文件**，音色可以从"电子正弦波"一路换到"真钢琴 / 真小提琴 / 真口琴"。

```
简谱字符串 ──→ 3.py ──→ WAV ──→ ffmpeg(音效+响度标准化) ──→ MP3
                 │
                 └─ 三种音源引擎：正弦波 / 287 种 GM 乐器 / 实验性采样器
```

## 1. 快速开始（三条命令）

```powershell
cd D:\deepseek\kouqin

# ① 最省事：内置示例（正弦波）
python -X utf8 3.py

# ② 换成钢琴（287 种 GM 音色之一）
python -X utf8 3.py "1 2 3 1|3 4 5-" --engine sf2 --gm 钢琴 -o 我的曲子.mp3

# ③ 看看有哪些音色名可用
python -X utf8 3.py --gm list
```

> **为什么都写 `-X utf8`**：Windows 默认用 GBK 读源码/输出，中文注释和文件名会乱码。加 `-X utf8` 一劳永逸。
> 如果嫌麻烦，也可以先执行 `chcp 65001` 再运行。

## 2. 简谱记号完整速查表

| 记号 | 含义 | 例子 |
|---|---|---|
| `1`~`7` | 音级（1 = 调式主音） | `1 2 3` = do re mi |
| `0` | **休止符**（时值写法同音符） | `1 0/ 2` |
| `#4` `b7` `♯4` `♭7` | 升号 / 降号 | `#4` = 升 fa |
| `1'` `1^` `1+` | **高八度**（可叠加） | `1''` = 高两个八度 |
| `1,` | **低八度**（可叠加） | `1,,` = 低两个八度 |
| `_1` | 低八度（另一种写法） | `_1 _2` |
| `（1）` `(1)` | 低八度（括号写法） | `（6）1 2` |
| `1-` | **延长线**：时值 +1 拍 | `5-` = 5 占 2 拍；`5--` = 3 拍 |
| `1/` | **减时线**：时值减半 | `1/` = 半拍；`1//` = 四分之一拍 |
| `1.` | **附点**：时值 ×1.5 | `1.` = 1.5 拍；`1..` = 1.75 拍 |
| `1:0.75` | **直接指定拍数**（万能写法） | `1:0.3` |
| `1~1` 或 `1 1~` | **连音线**（两种写法都支持） | 两个 1 合成一个 2 拍 |
| `空格` | 分句停顿 0.25 拍 | `1 2 3` |
| `\|` | 小节线（只为易读，不停顿） | `1 2\|3 4` |
| `\|\|` | 段落 / 换气，停顿 1 拍 | `...\|\|...` |
| `换行` | 停顿 1 拍 | 多行简谱 |

**时值可以叠加**：`1-` = 2 拍，`1/-` = 1.5 拍，`1./` = 0.75 拍，`1.` = 1.5 拍。

### 记号演示

```powershell
python -X utf8 3.py --demo 音阶与记号演示     # 把高低音/减时线/附点/升降号都过一遍
```

## 3. 三种音源引擎

| 引擎 | 参数 | 音色 | 速度 | 评价 |
|---|---|---|---|---|
| **正弦波** | `--engine sine`（**默认**） | 电子"嘀嘀"声 | 快 | 稳定可靠，做旋律骨架够用 |
| **GM 音源** ⭐ | `--engine sf2` | **287 种真乐器** | **极快**（22 秒音频仅 0.2 秒） | **推荐**：钢琴/小提琴/长笛/吉他… |
| 实验性采样器 | `--engine sampler` | 口琴采样 | 慢 | ⚠️ 有两个已知缺陷，**不推荐**（见 9.5） |

### 3.1 正弦波（默认）

```powershell
python -X utf8 3.py "1 2 3 4 5" -o a.mp3
python -X utf8 3.py "1 2 3 4 5" --vibrato 0.6 --amp 0.7 -o b.mp3   # 加颤音、调振幅
```

### 3.2 GM 音源 ★（推荐）

用 **GeneralUser GS**（30.8 MB，287 个预设）渲染，支持**任何 0~127 号 GM 音色**。

```powershell
# 用中文音色名
python -X utf8 3.py "..." --engine sf2 --gm 钢琴      -o p.mp3
python -X utf8 3.py "..." --engine sf2 --gm 小提琴    -o v.mp3
python -X utf8 3.py "..." --engine sf2 --gm 长笛      -o f.mp3
python -X utf8 3.py "..." --engine sf2 --gm 弦乐      -o s.mp3

# 或直接用音色号（0~127）
python -X utf8 3.py "..." --engine sf2 --program 48   -o s2.mp3

# 换音源文件（任何 SF2 都行）
python -X utf8 3.py "..." --engine sf2 --soundfont "D:\路径\别的音源.sf2" --program 0

# 混响量（0~127，默认 70）
python -X utf8 3.py "..." --engine sf2 --gm 钢琴 --reverb 110 -o 大厅钢琴.mp3
```

**可用的中文音色名（23 个）**：

```
钢琴 大钢琴 亮钢琴 电钢 八音盒 管风琴 口琴 吉他 尼龙吉他 钢弦吉他 贝斯
小提琴 中提琴 大提琴 竖琴 弦乐 合唱 小号 长号 萨克斯 双簧管 长笛 排箫
```

### 3.3 实验性采样器

```powershell
python -X utf8 3.py "..." --engine sampler -o s.mp3
```
⚠️ 已知问题：① 长音循环没有交叉淡化，会有"咔"声 ② 释放音相对主体偏响约 6 dB。
**要真口琴音色，请用下面的 sfizz 路线（第 7.1 节）**。

## 4. 命令行参数全表

```
用法: python -X utf8 3.py [简谱字符串] [选项]

位置参数
  简谱字符串            省略则跑内置《两只老虎》

音源
  --engine {sine,sf2,sampler}   引擎，默认 sine
  --gm 名称                     GM 音色名（--gm list 看全部）
  --program 0~127               GM 音色号，默认 0
  --soundfont 路径               SF2 音源文件，默认 GeneralUser GS
  --reverb 0~127                SF2 混响量，默认 70
  --sfz 路径                    SFZ 音源（sampler 引擎用）
  --vibrato 0~1                 颤音深度（仅 sine）
  --amp 0~1                     振幅（仅 sine），默认 0.5

音乐
  --bpm 数字                    速度，默认 120
  --key C/D/F#/'1=D'            调号，默认 C

输出
  -o, --out 文件名               输出文件名（.mp3 需 ffmpeg）
  --fx {none,light,harmonica,wide}  效果链，默认 light
  --lufs -16                   响度标准化目标（LUFS），off = 不做

其他
  --demo [名称]                 内置示例（--demo list 看全部）
  -h, --help                    帮助
```

### 效果链（`--fx`）

| 值 | 内容 | 适合 |
|---|---|---|
| `none` | 不做后处理 | 想要最原始的声音 |
| `light`（默认） | 高通 110Hz + 轻 EQ + 压缩 | 通用润色 |
| `harmonica` | 三段 EQ + 压缩 + chorus + aecho | 采样音色、口琴 |
| `wide` | harmonica + 立体声加宽 | 想要更宽的空间感 |

### 响度标准化（`--lufs`）

默认 **-16 LUFS**（流媒体标准），用 ffmpeg 的 `loudnorm`（EBU R128 真响度，不是简单调音量），运行时会打印前后对比：

```
响度标准化 -30.18 → -15.66 LUFS，峰值 -17.00 → -2.62 dBTP
```

## 7. 相关工具

### 7.1 简谱 → MIDI → sfizz（口琴 / 钢琴 SFZ 路线）★

**为什么需要它**：`sfizz` 是专业的 SFZ 音源引擎（你手上那套 basic-harmonica 口琴就是 SFZ 格式），但它**不读 SF2**。所以要先把简谱转成 MIDI。

```powershell
# ① 简谱 → MIDI（记号规则与 3.py 完全一致）
python -X utf8 D:\deepseek\tools\jianpu_to_midi.py "1 2 3 1|3 4 5-|5 6 5 4 3 1|1 5, 1-||" out.mid --bpm 120 --key C

# ② 用 sfizz 渲染（可选音源见下表）
& "D:\deepseek\basic-harmonica\tools\bin\Release\sfizz_render.exe" `
    --sfz "D:\deepseek\basic-harmonica\harmonica solo.sfz" `
    --midi out.mid --wav out.wav -s 44100 -q 2 --use-eot

# ③ 转 MP3 + 响度标准化
& "D:\deepseek\tools\ffmpeg\bin\ffmpeg.exe" -y -i out.wav `
    -af "loudnorm=I=-16:TP=-1.5:LRA=11" -codec:a libmp3lame -qscale:a 2 out.mp3
```

**可用的 SFZ 音源**：

| 乐器 | SFZ 路径 |
|---|---|
| 🎵 口琴 | `D:\deepseek\basic-harmonica\harmonica solo.sfz` |
| 🎹 钢琴（Crystal Piano） | `D:\deepseek\tools\piano-sfz\OXOP Crystal Piano No Pan.sfz` |

## 9. 常见问题排查

### 9.1 `ffmpeg` 找不到 / 只能输出 WAV

`3.py` 会按顺序找：**PATH → `D:\deepseek\tools\ffmpeg\bin\ffmpeg.exe`**。
若都没有，会自动改存 **WAV**（并打印提示），不会崩。
修复：确认 `D:\deepseek\tools\ffmpeg\bin\ffmpeg.exe` 存在，或把它加到 PATH（**改完要新开终端**）。

### 9.2 `sf2 渲染失败：没找到 Node`

装 Node.js，或把 `node.exe` 的路径加到 `3.py` 里的 `NODE_CANDIDATES` 列表。
本机 node 在 `C:\Program Files\nodejs\node.exe` ✅

### 9.3 报错里出现 `Permission denied` / `-13 EACCES`

临时目录不可写。让 Python 的临时目录指向可写位置：

```powershell
$env:TEMP = 'D:\deepseek\kouqin\.tmp'; New-Item -ItemType Directory -Force $env:TEMP | Out-Null
python -X utf8 3.py "1 2 3"
```

### 9.4 中文输出乱码

一定加 `-X utf8`：`python -X utf8 3.py ...`；PowerShell 里可先 `chcp 65001`。

### 9.5 `--engine sampler` 的声音不对

已知两个缺陷（不打算修，因为已有更好的方案）：
1. 长音循环没有交叉淡化 → 循环点有"咔"声
2. 释放音相对主体偏响约 6 dB

→ **要真口琴音色请走 7.1 的 sfizz 路线**，或 `--engine sf2 --gm 口琴`。

### 9.6 某个 SF2 无法加载

FluidSynth 对极少数 SF2 有兼容问题（实测你那个 `Harmonica_Essentials.sf2` 会被拒，而 GeneralUser GS 正常）。
判断方法：换 GeneralUser GS 试一下；能加载就不是引擎问题。

### 9.7 下载音源很慢

用 §7.4 的 `dl_gh.py`（多线程 + 正确续传）。国内通道实测：`ghfast.top` 可达（单连接约 166 KB/s），
jsDelivr 对 GitHub 文件有 **20 MB 上限**（大音源会返回 "File size exceeded"）。

### ⚠️ 已排除的弯路（别再试）

| 方案 | 结论 |
|---|---|
| Windows 自带 `gm.dls`（3.28 MB GM 波表） | ❌ FluidSynth 的 wasm 版**没编译 DLS 支持**，加载失败 |

| 用 `curl -o` 做断点续传 | ❌ `-o` 会截断文件，续传偏移量全乱（见 `dl_gh.py` 的正确做法） |
